# 研学计划

一个用于安排论文阅读、实验复现、研究周报等学习任务的静态网页工具。无需安装依赖，直接打开 `index.html` 即可使用。数据保存在当前浏览器本地，可通过 JSON 文件导入导出。

代码由华为云 AI 开发者空间的 CodeArts 辅助生成，随后进行源码检查、边界修正和实际界面验证。应用运行时不调用模型，也不连接云服务。

## 功能

- 添加、编辑、删除任务，记录预计分钟数和完成状态。
- 按已完成分钟数除以总分钟数计算进度，不按任务数量计算。
- 筛选全部、待完成、已完成任务。
- 本地保存计划；存储失败时显示提示。
- JSON 导入前整体校验，失败时保留当前计划。
- 示例计划需点击按钮载入，首次打开保持空计划。
- 中文界面，支持手机屏幕和键盘操作。

## 使用

双击 `index.html`；也可在项目目录运行本地静态服务器：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

再打开 `http://127.0.0.1:8080`。同一计划保存在同一浏览器、同一网站地址下，切换浏览器或地址时可通过 JSON 转移。

## 数据格式

导入文件的根节点为数组。每项只包含以下四个字段：

```json
[
  {"id":"reading-1","title":"阅读论文与整理笔记","minutes":90,"done":false}
]
```

最多1000项；ID为非空字符串且不重复；标题去掉首尾空格后为1至120个Unicode字符；分钟数必须为1至10080的安全整数；完成状态必须是布尔值。额外字段和缺失字段均会被拒绝。有效输入的总分钟数最多10,080,000，处于JavaScript安全整数范围内。

任务标题作为文本展示，不执行输入中的HTML。有效导入会替换当前计划，可先导出备份。清理浏览器站点数据会清除本地计划。

## 验证

安装Node.js后运行：

```sh
node test-core.js
```

核心逻辑验证包括分钟权重、空计划、数据类型、分钟与标题边界、重复ID、未知字段及任务数量限制。界面操作另行验证添加、完成、编辑、刷新后保存和错误导入保留数据。
